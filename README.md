# BYOND Microphone Patch

Отдельный обратимый патч разрешения микрофона WebView2 для **Windows BYOND 516.1685 и 516.1688 (x86)**. Последняя версия в официальном каталоге BYOND на 11.11.2026 — 516.1688. Патч не содержит и не распространяет файлы BYOND.

[Скачать Windows-установщик](https://github.com/TheSameEli/Byond-Mic-Patch/releases/latest)

## Установка для игрока

1. Скачать ZIP из Releases и распаковать в отдельную папку.
2. Закрыть все приложения BYOND, включая значок BYOND в трее.
3. Запустить `Byond-Mic-Patch.exe`, подтвердить запрос прав администратора, выбрать свою папку BYOND или BYOND/bin и нажать **«Установить патч»**.
4. Запустить BYOND и подключиться к серверу с офлайн-диктовкой TGUI.
5. Открыть **Настройки игры → Звук → Диктовка — микрофон и проверка**. Нажать **«Разрешить микрофон»**, выдать разрешение WebView2, выбрать устройство и выполнить **«Тест на 10 секунд»**. Тест ничего не отправляет в чат.
6. В игре нажать **Shift+T** для записи и повторно **Shift+T** для отправки; **Escape** отменяет без отправки. Если клавишу переназначили в настройках управления, использовать новое сочетание.

Первый запуск скачивает русскую модель с игрового сервера (44,1 МиБ). Аудио распознаётся локально. Во время записи есть лимит 30 секунд; по лимиту запись отменяется без отправки. Сам патч не добавляет распознавание: сервер должен предоставлять TGUI-диктовку.

## Откат патча клиента

Закрыть BYOND, запустить `Byond-Mic-Patch.exe`, выбрать ту же папку и нажать **«Восстановить BYOND»**. Альтернатива — `Restore-Patch.cmd` от имени администратора. Оригинал хранится в `byondwin.dll.before-microphone-patch` рядом с DLL; не удалять эту копию до отката. Обновление BYOND может заменить DLL; для неизвестной версии патч применять нельзя.

## Что изменяется

Патч меняет ровно 63 байта обработчика `ICoreWebView2PermissionRequestedEventHandler::Invoke` в `byondwin.dll`. Для микрофона используется DEFAULT вместо принудительного DENY — появляется штатный запрос WebView2. Это **не безусловное разрешение записи**. Решение остаётся за игроком; системные запреты Windows сохраняются. Поведение камеры, геолокации и остальных разрешений не расширяется. Патч не отключает проверки обновлений и не записывает/передаёт звук.

Установщик принимает только DLL, целиком совпадающие с SHA256 из встроенного `manifest.json`. Проверяет байты обработчика и ожидаемый SHA256 результата, сохраняет оригинал, выполняет замену через проверенный временный файл. Отдельная резервная копия другой версии не перезаписывается. Запущенный BYOND из выбранной папки блокирует запись. Повторная установка и повторный откат безопасно сообщают текущее состояние. Для EXE требуется Windows с .NET Framework 4.x и файловая система с поддержкой атомарного File.Replace (обычно NTFS).

Программа не подписана сертификатом издателя. SHA256 файлов находится в архиве, контрольная сумма самого ZIP опубликована рядом с релизом. Исходники открыты; установщик можно собрать самостоятельно.

## Исходники и сборка

- `src/Program.cs` — GUI и применение/откат патча.
- `manifest.json` — поддерживаемые оригинальные/изменённые SHA256 и точные байты.
- `Microphone-Patch.ps1` — альтернативное применение из PowerShell.
- `Build.ps1` — сборка EXE штатным C#-компилятором .NET Framework; дополнительные пакеты не скачиваются.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Результат — `artifacts/Byond-Mic-Patch.exe` и сопроводительные файлы. PowerShell-альтернатива:

```powershell
.\Microphone-Patch.ps1 -Mode Status -ByondDirectory 'D:\Games\BYOND\bin'
.\Microphone-Patch.ps1 -Mode Apply -ByondDirectory 'D:\Games\BYOND\bin'
.\Microphone-Patch.ps1 -Mode Restore -ByondDirectory 'D:\Games\BYOND\bin'
```

При работе с Program Files требуется окно PowerShell с правами администратора. Скриптовый вариант также проверяет полные SHA256, сохраняет оригинал и отказывается менять неизвестные версии. GUI имеет встроенный манифест; PowerShell использует файл манифеста рядом со скриптом.

## Поддержка и проверенные входные файлы

| BYOND Windows | SHA256 оригинального byondwin.dll |
| --- | --- |
| 516.1685 | cc0185b4b21b8f0187e3281d8bed9167df94bfbb494dccfa5d01ba00a94a4368 |
| 516.1688 | 160181fed9699847d9ec39dfb38e066540bc7a68378f0cd9c8ce2dff05530d69 |

516.1688 сверена со свежим официальным архивом: https://secure.byond.com/download/build/516/516.1688_byond.zip . Актуальные версии: https://www.byond.com/download/build/516/ . Другие версии, ОС и архитектуры не заявлены как поддерживаемые.

На отдельной копии 516.1685 пользователь подтвердил разрешение микрофона, тест распознавания и отправку речи через Shift+T в Primera. Поддержка DLL 516.1688 проверена по байтам/полной контрольной сумме официального архива; интерактивный запуск нового GUI и микрофона на 516.1688 отдельно не выполнялся. Автоматические тесты не запускались по запросу пользователя.

Лицензия кода установщика — MIT. BYOND остаётся продуктом своего правообладателя; оригинальные/полностью изменённые DLL в репозитории и релизе отсутствуют.
